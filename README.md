# ทะเบียนคุมค่าเล่าเรียนบุตร — ว 257

เว็บแอปแบบ Static ใช้งานบน GitHub Pages ได้ ไม่ต้องมี Server/Database

## ฟังก์ชัน
- ทะเบียนผู้มีสิทธิ เพิ่ม/แก้ไข/ลบ
- ทะเบียนบุตร เพิ่ม/แก้ไข/ลบ
- โรงเรียน / ประเภทสถานศึกษา / ระดับ / สายวิชา
- บันทึกรายการเบิก
- คำนวณยอดสะสมและคงเหลือ
- แจ้งเตือนรายการเกินเพดาน
- Dashboard
- Export Excel
- สำรอง/นำเข้าข้อมูล JSON
- แก้ไขตารางอัตราได้จากหน้าเว็บ
- ข้อมูลเก็บใน Browser localStorage

## วิธีนำขึ้น GitHub
1. สร้าง Repository ใหม่ เช่น `tuition-registry-w257`
2. อัปโหลด `index.html`, `style.css`, `app.js`, `rates.js`
3. เข้า Settings → Pages
4. Build and deployment → Source = Deploy from a branch
5. Branch = `main` / Folder = `/ (root)`
6. Save
7. รอสักครู่แล้วเปิด URL ที่ GitHub Pages แสดง

## สำคัญ
อัตราที่ตั้งต้นใน `rates.js` อ้างอิง ว 257 ลงวันที่ 28 มิ.ย. 2559 และ ว 22 ลงวันที่ 12 ม.ค. 2561 ตามข้อมูลเผยแพร่ของกรมบัญชีกลาง/หน่วยงานราชการที่รวบรวมหนังสือเวียน

ควรตรวจสอบหนังสือเวียนและหลักเกณฑ์ฉบับจริงก่อนนำไปใช้เป็นหลักฐานการอนุมัติ เพราะระบบเป็นเครื่องมือช่วยควบคุมทะเบียน ไม่ใช่ตัวแทนการตรวจสอบสิทธิของเจ้าหน้าที่

## ข้อจำกัดด้านข้อมูล
GitHub Pages เป็น Static Web และข้อมูลหลักเก็บในเครื่องของผู้ใช้แต่ละเครื่องผ่าน localStorage ดังนั้นข้อมูลจะไม่ซิงก์กันระหว่างคอมพิวเตอร์หลายเครื่อง

หากต้องการใช้ร่วมกันหลายคนในหน่วยงาน ควรพัฒนารุ่นถัดไปเป็น Google Sheets / Firebase / Supabase หรือฐานข้อมูลของหน่วยงาน
